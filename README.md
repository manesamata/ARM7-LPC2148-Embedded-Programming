This repository contains a collection of Embedded C programs developed using the ARM7 LPC2148 microcontroller. It covers fundamental microcontroller programming, peripheral interfacing, communication protocols, and hardware configuration.
The programs are organized into a single repository to document my practical learning and implementation of ARM7-based embedded systems.
Programs Included

1. LED Interfacing

LED ON/OFF control

GPIO output configuration

Basic digital output operations

2. Switch Interfacing

Push-button input detection

GPIO input configuration

Controlling outputs using switch inputs

3. LCD Interfacing

LCD initialization

Sending commands and character data

Displaying text and values

4. UART Communication

UART initialization

Serial data transmission and reception

Baud-rate configuration

Communication with a serial terminal

5. RTC (Real-Time Clock)

RTC interfacing and time management

Reading and displaying hours, minutes, and seconds

Working with time-related data

6. DAC (Digital-to-Analog Converter)

DAC configuration

Generating analog output using digital values

Understanding digital-to-analog conversion

7. PLL (Phase-Locked Loop)

PLL configuration

Understanding the feed sequence

Configuring the processor clock and peripheral timing

8. Timer

Timer initialization and configuration

Delay generation

Understanding timer registers and timing operations
